# Architecture Decision Records (ADR)

Registro de las decisiones de arquitectura de **Zarix**. Cada ADR captura el
contexto, la decisión tomada y sus consecuencias, en el formato estándar
(Título · Estado · Contexto · Decisión · Consecuencias). Los ADR son
inmutables: si una decisión cambia, se agrega uno nuevo que la supersede en
lugar de editar el viejo.
