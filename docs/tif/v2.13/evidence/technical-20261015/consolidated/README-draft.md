## Recuperación y sesiones

La corrida nativa nueva comenzó con SOURCE y RESTORE vacíos. Restauró 64 tablas —27 públicas, 27 Auth y 10 Storage—, datos, propietarios, grants, privilegios predeterminados, RLS, funciones, constraints, triggers y conteos/hashes. Comprobó una base separada literalmente vacía con `TEMPLATE template0` y un segundo stack de plataforma sin datos. Dos usuarios normales volvieron a login/getUser en RESTORE. Los bytes del objeto Storage se respaldaron aparte del dump y se descargaron con el mismo hash; dueño permitido, B y anon denegados. Dump y bytes permanecen privados en `/tmp`; la evidencia pública contiene contexto, conteos y hashes saneados.

El sign-out global revocó refresh. El JWT de acceso previo respondió 200 hasta su vencimiento registrado: **no se afirma revocación inmediata de un JWT stateless**. La capacidad de invitado se verificó inválida, rotada e inactiva, incluso frente a replay durable. El outbox sobrevivió restauración y claim; no acredita entrega real a Telegram. Ver el [alcance completo](../native-full/README.md).

El [reinicio E2E del 15/10](../environment/e2e-stack-restart.md) cambió PostgreSQL PID 56368 → 2947 y su inicio 00:03:06.982076Z → 01:41:24.642927Z. Las huellas de las 64 tablas y el esquema/grants permanecieron iguales antes de una sonda Auth posterior. SOURCE, RESTORE y LOAD conservaron sus archivos de estado y no recibieron conexiones de base de esta operación. El replay de recibo API posterior mantiene informe independiente; estos 17 checks no se suman a los 22 grupos nativos como casos originales únicos.

Chrome durable dejó cuatro movimientos y cuatro recibos, saldo 9900,01, y volvió a comprobar Auth normal de A/B. Su perfil temporal propio fue eliminado después de confirmar Chrome cerrado; quedan el estado privado 0600 del item seleccionado, fixture, SQL, capturas y hashes. Ese estado **no es un dump completo de IndexedDB** y no se ofrece el perfil bruto para auditoría posterior. El primer fallo de sockets EPERM y el fallo de selector posterior permanecen documentados; el arreglo del arnés no repitió los efectos financieros.

La UI no fue íntegramente double-only: el widget Mercados de inversiones invocó `/api/market-data`, cuyo servidor conserva lecturas públicas hardcoded a CoinGecko, Yahoo y Stooq. Hubo lecturas incidentales reales, sin credenciales ni datos personales ajenos; no son aceptación formal de esos proveedores. El ledger y las posiciones usadas como oráculo fueron sintéticos/manuales. Los endpoints configurables de cotizaciones y sus fallas inyectadas se distinguen de ese widget; una barrera de browser loopback no demuestra aislamiento de salida del servidor. Los perfiles LOAD sólo declaran el doble de cotizaciones CriptoYa/DolarApi/CoinGecko y deben observar sus requests antes de extender el alcance.

El gateway público E2E está en loopback, pero el [PostgREST interno escuchó wildcard](../environment/native-lifecycle-inspection.md), antes `*:27781` y después del reinicio `*:20877`. El CLI no expone una opción soportada para restringir ese binding del stack existente; no se midió accesibilidad LAN ni se modificó firewall, binarios o state. No se afirma que todos los sockets nativos sean loopback. CNF-04 conserva BLOCKED su contrato original completo. [FileVault observado actualmente](../environment/at-rest.json) sí acredita cifrado del volumen local que contiene este runtime y sus backups: el volumen permanece montado/desbloqueado y no se afirma cifrado individual de cada archivo ni garantía remota. Falta la aceptación exacta del contrato de proveedor/configuración y CP2-19 completo mediante API/JWT. RLS y esta evidencia local se documentan por separado. CNF-12 conserva pendiente su snapshot, RPO/RTO nominal y recorrido UI posterior exactos, aun con recuperación nativa demostrada aparte.

CNF-01 integral exige equivalencia del hardware, topología y dispositivo de despliegue. Los perfiles locales warm, proceso Node nuevo y outage tienen denominadores separados; los dobles HTTP 503 no prueban integración real. Los subrecorridos de lectura tampoco aprueban la suite completa de CP.
